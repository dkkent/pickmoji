# Emoji data source

`emoji.json` is generated by `scripts/update-emoji-data.sh` from:

- **Package:** [emojibase-data](https://www.npmjs.com/package/emojibase-data)
- **Version:** 17.0.0 (Emoji 17.0)
- **File:** `en/data.json`
- **URL:** https://cdn.jsdelivr.net/npm/emojibase-data@17.0.0/en/data.json
- **License:** MIT (`LICENSES/emojibase-MIT.txt`). The labels and tags are
  derived from Unicode CLDR annotations, covered by the Unicode License v3
  (`LICENSES/Unicode-License-v3.txt`).

## What the script keeps

Each entry is trimmed to `emoji`, `label`, `tags`, `group`, `order`, and
`skins` (each skin: `emoji`, `tone`). Entries are sorted by `order`.

Dropped:

- Entries with no `group` (the 26 regional indicator letters).
- Group 2, "Component" (skin-tone modifiers and hair pieces).
- Mixed-tone skin variants (where emojibase `tone` is an array, e.g. a
  handshake with two different tones). The tone picker offers the five
  uniform tones only.

Result: 1,914 emoji and 1,650 skin variants in about 308 KB.

## Runtime filtering

At launch, `EmojiRenderability` checks every emoji and skin variant against
the Apple Color Emoji font with CoreText and drops the ones the running OS
cannot draw. An emoji passes when it lays out as one run in the emoji font,
with no missing glyphs, and is exactly one emoji advance wide.

This was chosen over filtering by emojibase `version` against the OS version
because it tests the font that is actually installed: it needs no table of
"which macOS shipped which Emoji version", and it stays correct when Apple
ships emoji in a point release or when a specific sequence is missing.

The width check is what makes it reliable. Apple draws some sequences
(couples, kiss, handshake) as two glyphs composed into one cell, so "exactly
one glyph" would wrongly drop them, while an unsupported ZWJ sequence or an
invalid flag pair falls back to two full-width glyphs.

## Updating

```sh
EMOJIBASE_VERSION=17.0.0 ./scripts/update-emoji-data.sh
```

Then update the version in this file and in `SettingsView.swift` (About).
